🚀 HOW TO USE - COMPLETE PURCHASE FLOW:

STEP 1: Browse Products
   → Open index.html or shop.html
   → View available music products

STEP 2: Add to Cart
   → Click "Add to Cart" on any product
   → Cart counter updates automatically
   → Can add multiple items

STEP 3: View Cart
   → Click cart icon (🛒) or go to cart.html
   → Review items
   → Adjust quantities if needed
   → See price calculations

STEP 4: Enter Shipping Info ⭐
   → Click "Proceed to Checkout"
   → Fill out SHIPPING ADDRESS:
      • Email address
      • Full name
      • Street address
      • City, state, ZIP code
      • Country
      • Phone number

STEP 5: Enter Payment Info ⭐
   → Fill out PAYMENT DETAILS:
      • Card number (auto-formats)
      • Cardholder name
      • Expiry date (MM/YY)
      • CVV security code
      • Billing ZIP

STEP 6: Review & Purchase ⭐
   → Check order summary on right side
   → Verify all information
   → Click "🛒 PLACE ORDER NOW"

STEP 7: Order Confirmed! 🎉
   → See confirmation page
   → Order number generated
   → Receipt with all details
   → Can print confirmation
   → Cart is cleared
